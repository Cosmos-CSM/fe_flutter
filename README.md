# Flutter Extension

A repository for a framweork extensions package. Framweork extensions are CSM shaped utilities and tools for frameworks and languages used during development.

[Changelog](./flutter_extension/CHANGELOG.md)

## **Installation**

> Go to your Flutter **pubspec.yml** file and put:

```yaml
dependencies:
  flutter_extension:
    git:
      ref: <version>
      path: /flutter_extension
      url: https://github.com/Cosmos-CSM/fe_flutter.git
```

You will need read access to the repository, also to get the **version**, go to the GitHub repository look at releases and you'll be able to see available versions to use, consult [Changelog](./flutter_extension/CHANGELOG.md) for more version details.
